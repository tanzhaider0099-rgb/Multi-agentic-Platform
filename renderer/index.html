Welcome to Hydra

Four things, in order. Each works without the next — the app stays usable even if you stop halfway.

  1. 1. Create or open a project

    A project is a folder on your computer. Everything you ingest for it — raw files, processed notes, and its database — lives inside that one folder.

  2. 2. Add an OpenAI key

    Powers OCR, transcription, and embeddings by default. Without it, ingestion still stores raw text, but search won't work — unless you switch to offline Ollama in Settings.

  3. 3. Choose your "brain"

    The AI that writes research answers. Default is Anthropic. Add a key below, or switch to a fully offline model later in Settings → Providers.

Everything here can be changed later in Settings.
